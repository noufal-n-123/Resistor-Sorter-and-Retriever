# Resistor Sorter and Retriever

An automated system designed to identify, sort, store, and retrieve resistors based on their resistance values.

## 📌 Project Overview

The **Resistor Sorter and Retriever** is an automation-based project developed to simplify the process of identifying and organizing resistors.

The system aims to reduce manual effort and improve the accuracy and efficiency of resistor handling by automatically detecting resistor values and directing them to their appropriate storage locations.

## 🎯 Objectives

- Automatically identify resistor values.
- Sort resistors according to their resistance values.
- Store resistors in designated compartments.
- Retrieve the required resistor when requested.
- Reduce manual sorting and searching time.
- Improve accuracy and organization in electronic component handling.

## ⚙️ Working Principle

The system follows a sequence of operations:

1. A resistor is placed into the input section.
2. The system detects and identifies the resistor value.
3. The controller processes the detected value.
4. The mechanism moves the resistor to the appropriate storage location.
5. When a resistor is requested, the system identifies its location.
6. The retrieval mechanism collects and delivers the required resistor.

## 🧩 Major Components

- Microcontroller / Control Unit
- Resistor Detection System
- Sensors
- Sorting Mechanism
- Retrieval Mechanism
- Motor / Actuator System
- Storage Compartments
- Power Supply
